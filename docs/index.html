装在你电脑上的桌面程序

它可以改项目里的文件。写入和执行命令会停在会话里，等你点批准或拒绝。记住的内容留在这台机器上。macOS、Windows、Linux 都能装。

改文件
要改的路径和前后文本在对话里。点批准才会写入，点拒绝就停。
几个会话
标签可以同时开着。红点表示这一段还在等你处理。切走之后，原来那段还在。
记忆
记住的内容存在这台电脑上。
MCP 和技能
侧栏里有扩展和技能。对话里用 / 调用技能。
产物
写出来的文件会留在列表里，之后还能打开。
