Features

一个 Agent，全链路干活

不是聊天玩具，是具备完整工具链与权限体系的工作伙伴。

🛠️

23+ 内置工具

文件读写 edit_file、路径搜索 find_path、Shell 执行与后台任务、 网页抓取 fetch、图像生成、build_docx 文档产出……开箱即用。

🔐

权限边界可控

只读操作自动放行，写入与命令执行弹出确认卡，完整展示 diff 与命令内容。 工具级 allow / deny 名单，敏感操作绝不静默执行。

🧠

认知记忆

对话结束自动提炼长期记忆，加密 SQLite 存储、密钥不出本机。 新会话自动召回上下文——Agent 记得你的偏好与项目背景。

🧩

MCP 扩展生态

兼容 Model Context Protocol。在对话里说一句「帮我安装 Playwright MCP」， AI 自动下载依赖写好配置，重启会话即生效。

📦

Artifact 沉淀

Agent 产出的代码、文档、图片以卡片形式管理，支持 Markdown 渲染、 代码高亮、图片视频预览，一键在编辑器中打开。

⚡

本地 & 轻量

Tauri 2 + 系统 WebView，安装包仅 ~10MB。支持 OpenAI 兼容 API 与 llama.cpp 本地模型，数据不出你的机器。

Safety

权限确认，三步闭环

1

Agent 发起请求

写入文件、执行命令等敏感操作触发确认卡，完整展示 diff 或命令。

2

你做决定

批准或拒绝，一次一议；只读操作按策略自动放行，不打断心流。

3

结果可追溯

每次工具调用与产出都有记录，Artifact 面板随时回看。

Tech Stack

自研 Rust Agent Runtime

Astra 的底座是开源的 astra-core（Agent Runtime SDK）与 astra-memory（认知记忆引擎）——工具系统、权限策略、事件协议、Artifact 全部自主实现。
