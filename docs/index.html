01

它先说清楚要改什么

路径、改哪几行、前后分别是什么，全都摆在这张卡片上。不用猜它偷偷动了哪里。

02

你可以只批这一件事

批准是单次授权，不是对这个工具永久放行。下一次写入会重新问你，命令也是。

03

拒绝之后它不会硬来

文件保持原样，这一轮停在这里。你可以补一句要求，或者换个思路让它重来。

日常用它做什么

一个能动手的 Agent，不只是会聊

内置文件、命令、搜索这些工具。会话可以同时开几个，产物和记忆都留在本机。

多会话并行

几个标签一起开着，切走之后原来那段还在跑。红点表示那个会话正等你处理。

读写一个真实目录

选中工作目录之后，它在这个目录里读文件、编辑文件、按需搜索，不会跳出去乱翻。

跑命令，看得见输出

构建、测试、跑脚本都能交给他，输出直接回到会话里。要执行前一样会先停下来问你。

MCP 与技能

外部能力按 MCP 接进来。技能是给自己写的说明书，对话里用 / 就能调用。

产物集中查看

这一轮写出来的文档、脚本、图片都在 Artifact 里，点开就能看，不用回翻聊天记录。

能从检查点回来

对话历史落锚点，工作区留 git 快照。改坏了可以退回到之前的某一步。

手机上也能管着它

桌面端亮出二维码，手机扫码就绑定。出门在外也能看会话、补一句话，消息会排进电脑的队列。

边界是分级别的

不是一刀切地信任，也不是一刀切地拦

每个工具调用都会过一遍策略。只读的可以直接放行，会改变磁盘或对外部产生影响的要你点头，明显越界的直接拒绝。

L1 · 自动放行

只读的事

读文件、列目录、查资料这类不会留下副作用的操作，直接做，不打断你。

read_file放行
search放行
L2 · 需要确认

会改变东西的事

写文件、执行命令、调用会改状态的接口，先摆出来等你决定。批准只对这一件事生效。

edit_file确认
run_command确认
L3 · 直接拒绝

越界的事

工作目录之外、明显危险或者不符合当前范围的调用，硬拦，不留商量的口子。

../.ssh拒绝
rm -rf /拒绝

工具返回的内容按不可信数据对待。网页或文件里写着「忽略之前的规则」，也不会因此多拿到一点权限。

留在本机

记忆和密钥，都不往外送

会话、记忆、模型配置都写在这台电脑上。记忆库是加密的，密钥不离开本机；换台机器就换一份数据。
